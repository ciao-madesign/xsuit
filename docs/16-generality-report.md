# 16 — Generality report (B13): recognition without adapters

> Generated by `npm run corpus` from `tests/corpus/`. Do not edit by hand.

**What this measures.** The generic analyzer is run with **no site adapter** on 34 varied, synthetic, anonymous pages (kinds: app, aria-only, divsoup, divsoup-cjk, heuristic, minimal-page, protected, rtl, semantic, semantic-cjk, spa-shell, trap). Ground truth is marked in each page's HTML (`data-gt`). Only medium/high confidence counts as "usable", because rules never act on low.

**Limits (read before quoting).** The pages are synthetic and were written by the project, so this shows regressions and gross errors, not performance on the real web. Real pages are measured in B14. A page cannot be both realistic and fully independent of the author's expectations; the corpus therefore includes deliberate traps (look-alike markup, hidden elements, nested asides).

Recall on pages with semantic markup: **99%**; on pages built without it (div soup, apps, heuristics only): **33%**. The second number is the honest limit of generic recognition: where markup says nothing, xsuit does not guess.

Precision matters most: a wrong recognition can change the wrong element. Low recall only means xsuit leaves more of the page alone.

## Page type

Assigned a type on 12 of 34 pages; correct on 12 (precision 100%). Of 18 pages that have a handled type, 67% were typed correctly. Wrong types: none.
